# Arch Technologies Final Task

Social Network Platform developed for the Arch Technologies internship final task.

## Features

- User authentication
- User profiles
- Posts
- Image and video uploads
- Likes
- Comments
- Friend requests
- Real-time updates with Socket.IO
- Notifications
- Privacy settings

## Tech Stack

- React + Vite
- Node.js + Express
- MongoDB + Mongoose
- JWT
- Socket.IO
- Multer

## Project Structure

- client/ - Frontend
- server/ - Backend
